# Execution Plans (`docs/plans/`)

ExecPlan required for: changes across `scripts/` and `templates/`, public API
changes (validator CLI), or new subsystems. A checklist item in `TODO.md` is not
a substitute.

## Lifecycle
1. Author in `active/<name>.md` before starting.
2. Keep it a living document as reality diverges.
3. Move to `completed/` and check off TODO items when done.

## Required structure
Status, Owner, Started, Requirements, Boundaries, Scope, Background, numbered
Plan steps with completion criteria, Rollback, Risks/mitigations, Test plan.
