# Glossary

| Term              | Definition                                                            |
| ----------------- | --------------------------------------------------------------------- |
| Document role     | The single question a document answers.                               |
| Profile           | A named file-set + scope for the contract.                            |
| Control plane     | Files whose modification can alter agent trust; require human review. |
| Normative         | Authoritative; conflicting docs must defer to it.                     |
| Definition vs ref | An ID is a definition in its owner file; elsewhere it is a reference. |
| ADR               | Architecture Decision Record — why a choice was made.                 |
| ExecPlan          | A living implementation plan for substantial work.                    |
